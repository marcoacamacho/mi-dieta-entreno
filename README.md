# Mi Dieta y Entreno

App personal (Next.js) para llevar dieta alta en proteína y entrenamiento:

- **Hoy**: menú del día, calorías/proteína consumidas, comida fuera de menú, entreno del día con registro de peso levantado.
- **Compra**: lista de la compra semanal con checkboxes y artículos propios.
- **Recetas dulces**: postres altos en proteína y bajos en calorías.
- **Suplementos**: proteína whey, creatina y beta-alanina — dosis y dónde comprarlas al mejor precio.
- **Perfil**: calculadora de calorías/macros y evolución del peso corporal.

Todo el estado se guarda en el navegador (localStorage), sin backend ni base de datos.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
